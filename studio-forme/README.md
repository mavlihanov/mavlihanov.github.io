# Студия Форме

Сайт: https://mavlihanov.github.io/studio-forme/

Статический сайт салона: 9 категорий, 49 процедур, 55 вариантов продолжительности и цены. Запись: https://t.me/SYRA100.

Готовые файлы сайта находятся в этой папке. Исходные компоненты, каталог, сборка и проверки — в папке source. Установка зависимостей не требуется.

## Обновление

В папке source выполните npm run build и npm run check. После успешной проверки перенесите содержимое source/dist в родительскую папку studio-forme и отправьте изменения в main. GitHub Pages публикует статические файлы из корня main.

Файл _headers относится к исходному хостингу и не применяется на GitHub Pages. Свои серверные обработчики, вход в ChatGPT, внешние шрифты и сторонние скрипты сайту не требуются.

Обложка создана ImageGen как редакционный образ бренда; она не изображает помещение, сотрудника или результат процедуры. Лицензии шрифтов находятся в assets/FONT_LICENSES.txt.
